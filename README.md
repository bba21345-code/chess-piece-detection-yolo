# AI-Based Chess Piece Detection Using YOLO26

## Overview
This project uses the Ultralytics YOLO26 object-detection model to identify chess pieces in images.

## Technologies Used
- Python
- Ultralytics YOLO26
- Google Colab
- Computer Vision

## Features
- Chess-piece object detection
- Bounding-box visualization
- Class labels and confidence scores
- Model evaluation using precision, recall, and mAP

## Model Performance
- Precision: 94.2%
- Recall: 91.8%
- mAP50: 94.6%
- mAP50-95: 64.9%

These are the validation metrics reported by the training run.

## Prediction Results
The trained model was tested on a chessboard image and detected 19 objects in the displayed example.

## How to Run
1. Open the notebook in Google Colab.
2. Install the Ultralytics package.
3. Configure your Ultralytics credentials securely if required.
4. Run the training or inference cells.

## Security
API keys and other credentials must not be committed to this repository.
